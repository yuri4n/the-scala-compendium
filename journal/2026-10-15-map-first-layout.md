# Give the ecosystem map more space

## Context

The owner asked for a larger diagram, more ZIO and Kyo libraries, and removal
of the prominent featured panels. This updates the placement decision in
[featured projects](2026-10-15-featured-projects.md).

## Options

Keep the permanent sidebar and reduce node sizes, or use the full content
width with details beneath the map.

## Decision

Remove the featured panels. Expand the desktop content limit to 1920px and
the diagram to 780px high, with a 1100px minimum canvas width. Put details
below the map and provide a return action that focuses the selected node.
Keep project ownership and development status in nodes and details. Start
with ZIO selected. Add seven verified official modules each for ZIO and Kyo,
bringing the catalogue to 36 entries. Keep the four documented bridges and
the proposed three-way guide distinct.

## Reason

The diagram gets the primary space and its labels remain readable. Ownership
stays discoverable without a separate promotional section. More practical
libraries make the ecosystem regions useful beyond their core effect types.
