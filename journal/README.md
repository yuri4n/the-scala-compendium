# Journal

This folder records the decisions of this app. Write one file per decision.

- File name: `YYYY-MM-DD-topic.md` (the day of the decision, a short topic in kebab-case).
- Sections: Context, Options, Decision, Reason.
- Keep each file short. Link the commit or the pull request when there is one.
- Do not change an old entry when a decision changes. Write a new entry that names the old one.
